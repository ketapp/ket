Foundations

The tokens every component below is built from. Cards on a desk: the window ground is the darkest step, cards sit one step up, wells are set into cards, and anything that floats is lighter again. Colour is spent on state, never on decoration.

Inputs

One field recipe, ui::field, for every place a person types. A field is a recessed well with no edge at rest; the border arrives on hover, on focus and on a refusal. The label sits above in dim Geist; help and errors sit below.

Text field

36px tall, 13px Geist, 10px inset. A leading icon is dim; a trailing key hint is a kbd chip. Placeholder ink is one step under dim.

Textarea

Target spec: no shared multiline field exists in ui:: yet. Same well and focus ring as the text field, 1.55 line height, a footer row for the count, the send chord and the action.

Dropdowns and menus

ui::menu draws every menu: the + menu, context menus, pickers inside dialogs. It filters, draws and hands the chosen item back; what an item does is the caller's business. A select is a field-shaped trigger over the same menu.

Select

Target spec for a shared trigger: ui::menu::dropdown takes any trigger today. The trigger is a well like a field, the chevron flips while open.

Anatomy. A filter row when there are more than eight items; an icon column 20px wide so titles align with or without icons; the keyboard chord right-aligned in Geist Mono; hairline separators between sections and a dim heading when a section needs a name.
States. Hover and keyboard selection share one fill. Checked items carry a check at the far end. Danger is red ink, never a red fill. Disabled items stay in place at half ink so the menu does not change shape.
Surface. The float ground, a border and a two-layer shadow: one soft and far, one tight and near, so the edge holds on the dark desk.
